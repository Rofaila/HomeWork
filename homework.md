
# Devoir maison

## Question : Quelle est la difference entre Git et GitHub ?

### Réponse :
**Git** : c'est un logiciel local de gestion de versions qui suit l'historique des modifications du code sur l'ordinateur.
**GitHub** : c'est une plateforme qui héberge des dépôts Git en ligne pour faciliter le partage et le travail en équipe.
